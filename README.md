## Sobre o Projeto:
O Earthquake Monitor é uma aplicação desenvolvida em Python para consulta contínua de dados de uma API pública de terremotos. O projeto utiliza uma arquitetura assíncrona baseada em *threads* e filas para buscar dados em segundo plano, garantindo atualizações em tempo real sem travamentos e mantendo a interface totalmente responsiva.
O objetivo do projeto é demonstrar o tratamento de fluxos de dados contínuos, processamento concorrente e entrega de informações dinâmicas em tempo real.

## Tecnologias Utilizadas:
* Backend:
Python, Threading e APIS REST (JSON).
* Arquitetura:
Processamento assíncrono com filas e *threads*.

## Instalação e Execução:

Clone o repositório:
```bash
git clone https://github.com/seu-usuario/Earthquake-Finder.git
```
Acesse a pasta do projeto:
```bash
cd Earthquake Finder
```
Instale as dependências:
```bash
pip install -r requirements.txt
```
Execute a aplicação:
```bash
python main.py
```
